# Project Ideas and Domain Intent

## Documentation-Folder Audit Update

- FACT (`src/README_1st.md`): The central project idea is not "run scripts"; it is to understand how spatial knowledge is constructed through layered abstractions.
- FACT (`src/README_1st.md`): The pipeline transforms spatial observations into a justified decision space for optimized precipitation network design in Burgwald.
- FACT (`src/S2_features/doc/S2-meta.qmd`): A major didactic idea is that derived layers are constructed representations, not neutral data products.
- FACT (`src/S3_structure/doc/S3-meta.qmd`): Segmentation scale is treated as an operational stability problem, not a claim about true physical landscape objects.
- FACT (`src/S4_signatures/doc/S4-meta.qmd`): Signatures are representational contracts that make segments comparable and auditable.
- FACT (`src/S4_signatures/doc/04-3_signatures_RF-segs_classification.qmd`): The RF/CLC component is a semantic scale-transition exercise, not primarily a cartographic land-cover product.
- FACT (`src/S5-decision/doc/S5-meta.qmd`): S5 is where normativity becomes explicit; weights, thresholds, and selectors are value judgements.
- FACT (`src/S5-decision/05-9_decision_selector.qmd`): The practical decision idea is scenario-driven candidate construction, not a single universal optimum.
- INFERENCE: The strongest project idea is "traceable construction and comparison of spatial decision spaces" rather than a conventional end-to-end geoprocessing pipeline.
